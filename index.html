О проекте

Nakonechnik — сеть мини-игр на Terraria с общим хабом: строгие правила мира, свой HUD, монеты на аккаунте, магазин одежды и режимы с отдельным матчмейкингом. Сейчас идёт альфа-тест: сервер открыт, баланс и карты ещё живые — баги и идеи помогают двигаться быстрее.

Режимы

  • Race гонки по трассам
  • Arms Race дуэли с эскалацией оружия
  • One Shot снайпер, одна пуля — одно убийство
  • SkyWars острова, лут, последний выживший
  • Death Run бегуны против Смерти
  • Build Battle строй по теме на время
